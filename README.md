# GIFs de exercícios — lote 1

Ilustrações do [Flow Exercise Dataset](https://github.com/ozansozuozgit/flow-exercise-dataset/tree/961bb2739015da373daa43b960c28ee839fe93e6), arte declarada CC0-1.0 pelo projeto. Este lote converte quadros SVG para GIFs com fundo sólido e intervalo de 0,5 s. O tempo de reprodução não representa o ritmo recomendado. Movimento e equipamento foram conferidos visualmente; não houve revisão clínica nem verificação independente da origem da arte. Veja `FLOW-NOTICE.md` e `FLOW-CC0.txt`.

`manifest.json` relaciona ID do exercício, nome em português, equipamento e SHA-256 do GIF. Cada arquivo mantém o ID estável da variante do Flow.
